## B1. 文化倫理・データ主権(最重要・新規)

> 民族音楽データは知的財産法の外にあり「合法でも非倫理」がありうる。CARE/OCAP原則を採用。

1. 🔜 **CARE原則**(Collective benefit / Authority to control / Responsibility / Ethics)をデータ方針に明記
2. 🔜 **OCAP**(Ownership/Control/Access/Possession)= 提供元コミュニティが知識を統制
3. ⚠ 伝統曲・儀礼音楽は「世代間所有・著作者不明」で著作権保護外 → 法的に自由でも帰属表示・文脈明記の倫理的義務
4. 🔜 各調律に出自コミュニティ/地域/文化的文脈を記述(数値だけ抜き出さない=extractivism回避)
5. 🔜 「唯一正解でない/一具体例」をデータとUIに明記(普遍主義の否定、Leimma思想と一致)
6. 🔜 コミュニティからの訂正・削除要請の窓口(Issue/連絡先)を用意
7. ⚠ 西洋理論用語で非西洋音楽を記述する歪み(度数/和音概念の押付け)を最小化
8. 🔜 録音由来の実測値は録音者/アーカイブのライセンス確認(IASA倫理原則)
9. 🔜 reciprocity: 出典元への還元(リンク・クレジット・該当文化への送客)
10. 📋 将来サンプル音源を扱う場合は演奏者の同意確認(現状は数値のみ=低リスク)

## 新規の最重要発見

**B1 文化倫理が独立カテゴリとして浮上**。技術軸(前回C1-C10)では捉えていなかった。
- 伝統音楽は著作権の外 → 「合法でも非倫理」がありうる(extractivism)
- **CARE/OCAP原則**を Ruri のデータガバナンスに採用 → data-sourcing.md と統合
- 「数値だけ抜き出さない」「唯一正解と称さない」「出自コミュニティへの帰属/還元」を一級要件化
- これは Ruri の脱植民地スタンス(Leimma思想)を**運用レベルで具体化**するもの
