# UI Research — Ruri 操作系設計 (優先順位2)

> 微分音・多楽器の操作をどう見せるか。同種ソフトのUI定石と差別化の再評価。

## 微分音入力UIの定石: アイソモーフィック鍵盤

- **同じ和音=同じ形**: アイソモーフィック配列は、根音に依らず和音/音階の手形が同一。Lumatone(280六角キー)が代表。移調しても形が変わらない=微分音でも運指が一定。
- **任意EDO対応**: 19/22/31/53-EDO や純正律ラティス、非オクターブ(Bohlen-Pierce)を物理運指を変えず割当可能。
- **色マッピング**: 「音と音の間の音」を色で可視化。スケール/和音/調律を色で表現。
- **学習効果**: 和音・音階の形が不変ゆえ、理論知識が薄くても直感的に弾ける。
- → Ruriのweb鍵盤は **Halberstadt(伝統白黒鍵)でなくアイソモーフィック六角格子** を主候補に。`generatedScale`(MOS)が既にこの配列の数学的基盤。色=協和度 or 音度。

> 注: 12音以下なら伝統鍵盤+学習でも可だが、12超・非オクターブではHalberstadtが破綻。Ruriは任意調律前提ゆえアイソモーフィック優位。

## 協和可視化の定石: dissonance curve / heatmap

- 既存ツールが確立した表現:
  - **2音=2D曲線**(x:周波数比, y:粗さ)、12-TETグリッドを背景に極小=協和を表示(Datawrapper/jjensen/aykutcaglayan/ScaleExplorer)
  - **3音=2Dヒートマップ**(3D不協和曲面の投影、谷=協和)(bionichaos)
  - **リアルタイム和音値**: 演奏中の和音の粗さを単一数値で常時表示(xenboard, Euler Gradus併用)
  - 導関数プロット(dy)で極小点を明示(ScaleExplorer)
- Ruriの `dissonanceCurve`/`localMinima` は既にこの表示のデータを出せる。**timbre切替で曲線が変わる**のが核(competitive分析の差別化と一致)。

## 競合の再評価(重要 — 差別化の精緻化)

**xenboard-actm**(GitHub, 2022/23 学生プロジェクト)が **アイソモーフィック鍵盤 + リアルタイム協和表示(Sethares + Euler)** を既に統合。Ruriの「協和×演奏可能性の同時提示」の鍵盤版が部分的に既存。

→ Ruriの差別化を精緻化する必要:
| 軸 | xenboard等 | Ruriの残差別化 |
|----|-----------|---------------|
| アイソモ鍵盤+協和 | あり | — (もはや新規でない) |
| **実楽器の運指**(ギター/箏/ウードのフレット・弦) | なし | **Ruri独自**(弾けるか+最小コスト) |
| **DTM出力**(SMF/Scala/MPE/MTS/.tun) | なし/限定 | **Ruri独自**(DAWへ繋ぐ) |
| **世界の実測調律**(出典付きマカーム/ガムラン) | なし | **Ruri独自**(provenance) |
| harmonicity併用(粗さ単独でない) | Euler Gradus等単一 | Ruri=粗さ+Stolzenburg二軸 |

**結論**: 「協和可視化」「アイソモ鍵盤」は単体ではコモディティ化済。Ruriの非代替価値は **実楽器運指 + DTM出力 + 出典付き世界調律** の3点。UIはこれらを前面に出す(鍵盤や協和曲線は「あって当然」の土台、主役は運指図と出力)。

## 改善点 → Plan/GOAL-AUDIT 反映

1. **鍵盤UIはアイソモーフィック六角格子**を主候補(任意調律で運指不変)。伝統鍵盤は12-TET時のオプション
2. **協和は2D曲線 + リアルタイム数値**で表示、timbre切替を前面に(土台機能)
3. **UIの主役を「運指図 + DTM出力」に**(協和可視化・鍵盤はコモディティ化済、差別化はこちら)
4. **色は補助、数値/テキスト必須**(A11y: 協和・音高を色のみに依存させない=EAA要件と一致)
5. xenboard等を README の関連プロジェクトに記載(誠実・evenhandedness)

## UI最小構成(優先順位2の実装範囲)

```
[調律選択(出典表示)] → [スケール/和音生成] →
  ├ アイソモ鍵盤(色=音度, クリックで試聴 detune)
  ├ 運指図(楽器選択: guitar/bass/piano, K-best, 左手)   ← 主役
  ├ 協和パネル(粗さ曲線 + harmonicity数値, timbre切替)
  └ 出力(SMF/Scala/MPE DL + Web MIDI送出)              ← 主役
```
A11y: 全要素キーボード操作、aria-label、協和値テキスト併記、コントラスト4.5:1。
