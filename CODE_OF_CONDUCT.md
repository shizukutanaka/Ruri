# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), v2.1.

In short: be respectful and constructive. Harassment and discrimination are not tolerated.

Given Ruri's subject matter, we hold an additional standard: **engage with the world's musical traditions respectfully**. Do not present any tuning as universally "correct," and credit the communities and scholarship that data comes from.

Report unacceptable behavior via the repository maintainer (GitHub profile contact).
