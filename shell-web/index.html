Ruri 流離

world tuning → chord → DTM

世界の調律(12平均律から非西洋の微分音まで)で和音を組み、楽器スペクトルに基づく協和度と運指、 DAWへの出力までを一つに。各調律は出典付きの一具体例であり、唯一の正解ではない。

調律 / Tuning

和音 / Chord

アイソモーフィック格子 / Isomorphic board 同じ形 = 同じ和音

協和(音響指標) / Consonance

感覚的粗さ(Plomp-Levelt/Sethares)–
周期性(Stolzenburg, 小=協和)–

協和は音色に依存する(同じ和音でも音色で粗さが変わる)。これは音響記述子であり、 文化的な美的判断ではない。非西洋の調律が音響的に粗くても、その文化では協和でありうる。
